# Issue and pull-request labels

Use the existing labels consistently:

- `bug` — reproducible incorrect behavior.
- `enhancement` — a requested capability or improvement.
- `documentation` — documentation-only changes.
- `repository-hygiene` — findings from the repository hygiene audit.
- `status:in-progress` — an issue currently being implemented.
- `good first issue`, `help wanted`, `question`, `duplicate`, `invalid`, and
  `wontfix` — standard routing and triage states.
- `codex` — work specifically produced or coordinated by Codex automation.

Prefer an existing label over creating a synonym. Keep descriptions concise
enough to define the label's boundary and avoid removing labels that are still
attached to open work.
